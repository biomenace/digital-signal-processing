Digital Signal Processing

Self-contained HTML labs: sliders, live canvas plots, instant feedback. Nothing to install - just open a lab in the browser.

Pick a lab below. It opens as a normal web page: move the sliders, watch the plots redraw, hover the highlighted terms for hints. Every lab has a link back to this index in its top-left corner. Lab material is in Russian.

The grey line under a lab title lists the mathematical, signal-processing and data-science techniques that lab introduces. Each technique appears once, in the lab where it is first taught.

Notebook next to a lab opens its Python companion on GitHub, already executed — code, numbers and plots included. That is the part you hand in. The Open in Colab badge runs the same notebook in the browser, with no local Python installation.
