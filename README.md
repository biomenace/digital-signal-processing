## The notebooks

Each lab has a Python companion notebook. The lab page is the intuition -
sliders and live plots; the notebook is the same material done with real
code on real data, and it is what you hand in.

Every notebook here was executed before it was committed, so the numbers
and the plots are already in the file - GitHub renders them on the page,
and you can read a whole lab without running anything.

To run one, press its **Open in Colab** badge: it opens in the browser,
with nothing to install. The first cell installs the libraries it needs,
and any dataset is downloaded by a cell inside the notebook, so there are
no other files to fetch. Colab opens the notebook in playground mode -
use *File -> Save a copy in Drive* before you start working in it.

Locally the same file works in Jupyter: download it and open it.

## Layout

```
index.html        lab index, links to every lab
labs/*.html       one self-contained lab per file (HTML + CSS + JS inline)
notebooks/*.ipynb the Python companion to each lab, already executed
```

The site is served by GitHub Pages straight from this branch. Each lab is
a single file with no local assets, so it also works if you download it
and open it from disk. The only external request a lab makes is to a
MathJax CDN for formula rendering.
